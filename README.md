# Grok 4.6 developer speedrun

Shareable results from a curated Terminal-Bench 2.0 speedrun of Grok 4.6
through five coding harnesses, routed through MERGE Gateway.

## Headline results

- 13 of 15 trials verified (86.7%)
- 76.4-second median time to a verified solution
- 22.6 verified solutions per agent-hour
- Grok Build had the fastest harness median at 61.4 seconds
- Approximately $2.13 in API usage at rates available during the run

## Contents

- `data/trials.csv`: trial-level results used in the report
- `data/summary.json`: aggregate metrics and methodology
- `media/grok-4-6-speedrun-tweet.png`: current 1920×1080 X social image
- `media/grok-4-6-speedrun-tweet.svg`: editable source for the image
- `post/tweet-copy.md`: proposed X post
- `METHODOLOGY.md`: scope, timing rules, limitations, and reproducibility notes

## Positioning

This is a curated marketing speedrun, not an official Terminal-Bench leaderboard
submission. Do not describe it as a full Terminal-Bench 2.0 score.

The underlying Harbor job directories and trajectories are intentionally omitted
from this share bundle. They can be provided privately for audit if needed.
